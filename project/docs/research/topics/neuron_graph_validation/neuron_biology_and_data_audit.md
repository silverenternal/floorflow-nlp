# 神经元行为差距与训练数据审查

日期：2026-11-07

## 结论先行

目前没有一个科学上有限、完整的“真实神经元能做的任务列表”，所以不能诚实地给出“我们做不到其中多少项”的总数。神经元类型、所在脑区、发育阶段和状态不同，输入输出能力也不同；很多单细胞能力仍是按受控刺激下的生理响应定义，而非互斥的日常任务类别。

可做的严谨比较是把文献中的可观测行为抽象成能力测试，例如分组输入的非线性组合、时间依赖、局部记忆和可塑性；只在目标能力确实需要时模拟对应生理细节。项目不以复刻完整细胞为目标。当前模型在低维合成路由任务上有可学习的连续非线性状态转换，但没有验证这些能力族。其已知短板既包括连线策略未学好，也包括拓扑接口丢失多重接触、输入分组和事件时间等信息。

## 当前代码实际实现的行为

审查对象：`src/newera/neuron/composition.py`、`src/newera/neuron/graph/topology.py`、`src/newera/neuron/graph/policy.py` 及 v9 数据生成器。

- `ModelNeuron` 接受定宽连续向量、上一时刻消息、每条入边的标量 strength 和离散 edge type；同一模型参数作用于所有神经元身份。
- 一个更新步先把所有入边做全局加权求和，再经过 `tanh` 和 `GRUCell` 更新连续隐状态，最后输出定宽连续消息向量。
- `ModelNeuronGraph` 下一步才把上一时刻的输出沿边传递；它有显式身份状态和可变图规模。
- `LinkProposalPolicy` 在图模型外根据模型向量提议 keep/add/remove/retype/strength 更新。它不是细胞局部可塑性过程。
- `NeuronGraphTopology.validate` 禁止重复有向节点对，因此一个源神经元到同一目标神经元最多只能有一条合并后的边。

这意味着当前模型有一般非线性和隐状态，理论上可能近似一些非线性/时间映射；但“理论上可近似”不等于能力已经通过任务验证。未显式模拟某种生理机制也不自动等于能力缺失；应比较其在目标任务上的输入输出表现。

## 可观测能力差距

| 生物行为/能力 | 当前实现情况 | 判断 |
|---|---|---|
| 单细胞非线性输入整合 | `tanh`/GRU 有全局非线性，但入边先全局求和；没有按树突分支做不同运算 | 有一般非线性；分支条件行为没有显式表达或验证 |
| 分支位置、时空聚集与局部电事件 | 拓扑边没有树突区段/分支/距离，节点对不能有并行边 | 结构信息被接口合并；不能区分若干在总和相同、但位置与局部时序不同的输入模式 |
| 膜电位、动作电位、发放率、爆发、适应、不应期 | 输出是连续向量；GRU state 可携带历史，但没有电压、spike event/time、阈值/reset 或不应期语义 | 这些具体生理量无法由当前接口直接输出；抽象隐状态不构成验证 |
| 突触时间与短期/长期可塑性 | 没有 presynaptic/post-synaptic spike traces 或在线突触更新规则；strength 更新由外部策略决定 | STDP/频率依赖可塑性等局部行为缺失 |
| 兴奋/抑制和细胞类型差异 | edge type 是可学习的离散嵌入，无生理符号、递质/受体语义；模型不接收细胞类型/区域/形态条件 | 可学习“关系标签”，不能声称已实现真实 E/I 或 cell-type physiology |
| 任意多条入边与参数共享 | 图规模和每节点入度没有固定上限；所有节点共用一份模型权重 | 工程上支持可变入度；没有验证几千突触下的生理输入整合或稳定性 |

真实锥体神经元的树突可按分支形成非线性计算子单元；同一分支邻近输入与跨分支输入可能有不同整合规则。人类皮层 L2/3 锥体细胞的渐变型树突钙动作电位也被证明可对线性不可分输入进行分类。这些结果说明分组输入和非线性交互是值得纳入的能力假设；项目可以用抽象计算模块实现，不必复刻真实树突、钙电流或波形。当前全局求和可能丢掉完成这类任务所需的分组线索，因此要通过明确的任务测出影响。[Poirazi et al., 2003](https://pubmed.ncbi.nlm.nih.gov/12670427/), [Polsky et al., 2004](https://doi.org/10.1038/NN1253), [Gidon et al., 2020](https://pubmed.ncbi.nlm.nih.gov/31896716/)

尖峰与可塑性也不是单一固定曲线：常用简化发放模型需显式建模 spike/reset 与恢复状态，STDP 数据需要前后突触尖峰时序，频率效应甚至不能由简单成对规则完整描述。[Izhikevich, 2003](https://www.izhikevich.org/publications/spikes.pdf), [Pfister & Gerstner, 2006](https://pubmed.ncbi.nlm.nih.gov/16988038/)

神经元类型存在形态、电生理、转录组和连接特征上的差异。因此“同架构/同权重”可作为项目的统一人工抽象，但不能直接推出所有生物细胞类型功能相同；第一轮生物参照实验应固定为一个细胞类型/脑区，不能把异质细胞数据混成一个无条件目标。[Gouwens et al., 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7781065/)

## v9 训练数据审查

### 数据从哪里来

v9 没有加载外部数据集。样本由 `project/scripts/experiments/training/neurons/graph/run_neuron_graph_sparse_evolution.py::_data` 运行时生成；配置为 `project/configs/models_training/learning/neuron_comparisons/topology_evolution/modelized_neuron_shared_weights.json`。

数据是可复现的合成 keyed-memory 数据：每个例子生成离散 key、均匀随机标量 value、查询 key、随机槽位排列、两条初始候选边和确定性 target。任务包括：

1. single-link：目标为 `0.60 × queried_value`；
2. two-link：目标为 `0.60 × queried_value + 0.35 × cyclic_successor_value`。

训练池为 16 个 memory nodes，key-space 为 64，edge type 为 2 类。任务和 oracle topology 都由同一生成器定义。训练使用任务回归损失，没有把 oracle edge/action 作为策略监督；验证与测试使用独立随机种子，但仍从完全相同的生成分布采样。

### 这份数据“靠谱吗”

- **对窄问题靠谱**：随机种子可复现、输入与目标规则明确，适合查数据流、身份置换、梯度通路、任务路由及硬拓扑操作是否正确。
- **对生物神经元问题不靠谱**：没有真实膜电位、电流注入、spike train、树突形态/位置、突触生理或细胞类型标注。v9 通过不等于模型学会了任何已知的生物神经元行为。
- **对广义能力外推不够**：测试集虽独立，但只是同一个手工规则的新随机样本；没有新任务族、分布外输入、跨细胞/动物/实验室复现。
- **生成器定义答案，也定义结构真值**：这让窄目标容易解释，但结果只验证对作者指定的任务定义是否适配，不提供独立生物学真值。

因此应将 v9 标为“合成系统/连接工程验证集”，不能叫神经元行为训练集或生物神经元数据集。v9 的连接结构失败是真实的算法失败；即使结构指标通过，也不能据此判定生物行为得到复现。

## 如何用生物证据启发能力，而不追求完整生理模拟

1. **从有证据的计算现象提炼能力测试**：优先做分组输入的非线性交互/特征绑定、任意入度聚合和时序记忆等测试。可把同枝/跨枝的生理结果抽象为分组输入任务，不必保留真实树突几何或离子通道。
2. **区分任务输出与生理轨迹**：如果模型只需给下游传递一个连续消息，就不必强制产生动作电位波形；只有当阈值事件、脉冲时序、适应或不应期能提升目标能力时，再加入相应接口和测试。
3. **真实数据是证据源，不是唯一训练目标**：Allen Cell Types 提供小鼠/人类细胞的电生理、形态、转录组和模型文件，可用于选择行为范围或拟合有用动态；模态配对并非每个细胞都完整，数据库也不是通用任务数据集。[Allen Cell Types Database](https://celltypes.brain-map.org/)
4. **树突局部计算做能力抽象**：若分组/交互任务证明全局求和损失信息，可在模型内部加入可学习的分组通道、交互或多阶段聚合。可以保留源到目标的多条接触和局部状态，但无需复刻实际空间距离，除非该信息对任务指标有贡献。
5. **按结果补机制**：是否加入 spike-time plasticity、多个时间尺度、细胞类型条件或持续拓扑学习，由目标能力的对照实验决定。所有神经元仍共享同一架构与一份权重，状态按实例分开。未通过任务的能力需实现或重设表示；与能力无关的生理细节不列为欠账。

## 边界

神经科学当前不提供穷尽所有“真实神经元任务”的封闭清单。NewEra 的目标是持续扩展可组合计算能力，并在有价值处吸收生物启发；验收以操作化能力任务为准。某些维度可以比生物单细胞更强，但必须用明确任务、容量/计算预算和泛化结果证明；不需要追求无关生理细节的一一对应。
