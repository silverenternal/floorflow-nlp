# NE-019 稳定身份神经元的任务驱动动态连线验证

状态：MPS 六种子筛查完成。两类合成路由任务都学到离散连接并通过预先约定的结构与相对质量门槛；结果不外推到自然语言或通用能力。

## 复现与范围

- 配置：[graph_validation_learned_identity_links.json](../../../../../../configs/models_training/learning/neuron_comparisons/graph/graph_validation_learned_identity_links.json)
- 运行器：[run_neuron_identity_validation.py](../../../../../../scripts/experiments/training/neurons/graph/run_neuron_identity_validation.py)
- 逐种子原始结果、成本、规模和哈希：[design_validation.json](design_validation.json)
- 命令：`uv run --extra dev python project/scripts/experiments/training/neurons/graph/run_neuron_identity_validation.py --output project/docs/research/topics/neuron_graph_validation/validations/learned_identity_run/design_validation.json`
- 设备：MPS；不可用时 runner 明确失败，不切回 CPU。六个种子：11、23、37、41、53、67；每个 task/model 训练 1,000 步。
- 每个图有 8 个固定身份记忆神经元和 1 个 readout 神经元。身份为 key 0–7，与 token 位置无关；同一组 ID 在不同 batch graph 重复出现。训练没有边标签，策略仅从任务损失通过连续期望边权获得梯度；测试时按固定 0.5 阈值生成离散拓扑。
- 两个任务分别要求一条查询连线和两条查询连线。训练、验证、测试使用不同随机值/查询数据。模型在固定身份节点池上测试，不代表跨运行 ID 注册或开放式神经元生长。

## 判定规则

| 检验 | 预先冻结的门槛 | 结果 |
| --- | --- | --- |
| 连线结构 | 测试 edge precision、recall 均值至少 0.8；不同查询导致的连线变化率至少 0.75 | 两个任务均为 1.00 / 1.00 / 1.00，6/6 种子满足 |
| 任务效果 | 相对 MSE 比两个控制都至少低 20%，且六种子配对相对差值的双侧 95% t 区间上界小于 0 | 两任务相对两控制均满足 |
| 参数匹配 | 参数量误差不超过 5% | 6,230 对 6,233，误差 0.048% |
| 线性 MAC 匹配 | 每样本线性 MAC proxy 误差不超过 5% | 43,648 对 43,684，误差 0.082% |

这些门槛仅用于本配置的筛查，不是跨任务通用的神经元标准。相对误差按每个种子先配对计算，再汇总均值、样本标准差与 95% t 区间。

## 测试结果

| 任务 | 图模型测试 MSE | 参数匹配 MLP MSE | 线性 MAC 匹配 MLP MSE | 图模型 edge F1 | 查询变化连线率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 单链接检索 | 0.000120 ± 0.000054 | 0.005222 ± 0.000777 | 0.002492 ± 0.000589 | 1.00 | 1.00 |
| 双链接组合 | 0.000595 ± 0.000436 | 0.009824 ± 0.002410 | 0.002987 ± 0.000327 | 1.00 | 1.00 |

图模型相对参数匹配 MLP 的配对相对 MSE 差值为 −97.7%（单链接，95% CI [−98.8%, −96.5%]）和 −94.3%（双链接，95% CI [−98.1%, −90.5%]）。相对线性 MAC 匹配 MLP 为 −95.1%（95% CI [−97.0%, −93.2%]）和 −80.7%（95% CI [−94.1%, −67.4%]）。随机选取相同数量连线的拓扑明显变差，图减随机拓扑 MSE 均值分别为 −0.756 和 −1.281。查询条件连线变化率按测试样本的相邻 8 个候选配对窗口计算；每个种子的比较对数约 857–884，原始 JSON 记录配对数与逐 seed 变化率。

这说明策略在该固定身份任务上确实学会了按查询选择单边/双边连接；它补上了 v3 中“动作全 keep”的证据缺口。此任务刻意让跨身份路由成为解决问题的直接机制，不能据此推断一般图网络都优于 MLP。

## 计算与 MPS 成本

图模型有 6,230 个参数；参数匹配 MLP 为 6,233 个参数。线性 MAC 匹配 MLP 每样本为 43,684 MAC，图模型为 43,648。线性 MAC 只计 `Linear` 层，不含 scatter/reduce、逐元素操作、非线性、优化器和内存流量，所以这是明确标注的 MAC proxy，不称为完整 FLOPs 匹配。

MPS 上每个模型、每个任务训练 1,000 步的平均秒数：图模型 16.61 秒，参数匹配 MLP 0.43 秒，线性 MAC 匹配 MLP 0.45 秒。图策略的 MPS 训练开销约为两个控制的 37 倍；动态连线收益伴随显著的当前实现开销，尚未优化。

全有向候选边的 MPS 前向规模测量（batch=1）：

| ---: | ---: | ---: | ---: |
| 8 | 56 | 2.73 | 2.91 |
| 16 | 240 | 2.72 | 3.00 |
| 32 | 992 | 2.87 | 3.08 |

MPS current allocated 在同一 2 ms 采样窗口测到的临时增量随运行波动较大（本次约 1 KiB 至 17.77 MiB），不能据此拟合内存复杂度；短峰可能漏采，driver allocator 还包含缓存。训练阶段 host RSS 与 MPS allocated 均另行保留在原始 JSON。RSS、参数字节数、线性 MAC 和 MPS allocated 分开记录，不能互相替代。

## 身份生命周期与边界

`NeuronGraphTopology.remap_node_ids` 按稳定 ID 重排拓扑：保留仍存在的节点间连线，删除节点及其关联边，新 ID 以断连状态加入；调用者可之后显式连边。每张 graph 内有效 ID 唯一，batch 中不同 graph 可重复同一身份。若因果图重排会形成逆因果边，操作会拒绝。跨进程身份注册表和 checkpoint 持久化仍由调用者负责。

v3 原始 MPS 限制文案曾把采样计数误称为快照；已在 v3 结果的限制字段和本报告中更正口径，没有更改测量值。v4 配置从源头写明 2 ms 采样及短峰遗漏限制。

## 结论

前一轮的主要指标缺口已转化为可运行的检验：策略由任务目标驱动、离散拓扑随稳定身份输入变化、结构效用对比了等边数随机拓扑、控制分别匹配参数和线性 MAC，MPS 训练与规模成本也被测量。**当前剩余的工程代价是图模型训练慢约 37 倍；科学边界是实验仍为两个合成任务、固定神经元池和单机 MPS。** 不据此宣称自然语言收益或神经元全能性。
