## 范围与解释

每个节点由身份化特征向量表示，全部候选边共用同一个 encoder、link policy、graph propagation layer 与 readout。因而 v8 评估的是共享参数图路由策略能否学习合成检索/组合任务，不是“一个神经元是一个模型”。项目方向现已明确要求一个神经元是可独立实例化、执行和训练的模型单元。v6–v8 的结构指标、身份注册表和性能结果只能作为路由工程代理基线；在 NE-022 建立模型化神经元及组合契约前，不据此继续宣称验证了神经元本体。

配置：[topology_evolution_invariant_fastpath.json](../../../../../../configs/models_training/learning/neuron_comparisons/topology_evolution/topology_evolution_invariant_fastpath.json)。机器结果与注册表快照：本目录的 `topology_evolution_results.json`、`identity_registry.json`。配置冻结后使用 6 个未在 v5–v7 用过的训练/验证/测试种子，每个任务 6 个 seed；验证集选择离散动作阈值，独立测试集只评估一次。设备为 Apple MPS，PyTorch 2.15.0。

## 工程与性能复核

- 按持久 ID 排序生成固定形状候选，移除 MPS `nonzero` 动态形状路径后，测试样本随机槽位置换的身份边 Jaccard 从 v7 的 0.833/0.667 到两任务 1.000，MSE 相对漂移为 0。预测最大绝对差在聚焦 MPS 检查中为 0。
- 将训练子批次的边索引重映射改为张量向量化，并删除持续演化循环中重复执行的一次完整指标计算。v8 图模型训练均值为 8.08 秒/1200 步；v7 为 79.09 秒/1200 步。该跨版本比较不是同一种子的配对基准，运行噪声和其他代码差异未隔离，故只作为明显的工程信号，不作精确加速比承诺。
- 单样本前向中位数：4/16/32/64 个节点分别为 3.55/3.48/3.51/3.50 ms；64 节点的 2 ms 采样 MPS 已分配内存增量约 0.39 MB。样本量小，不能外推渐进复杂度或峰值内存。
- 图模型 7,168 参数，Linear MAC 代理 240,000/样本，乘加小计 480,000 FLOPs。MAC 不含 scatter/reduction、逐点运算、激活、优化器、内存搬运和融合；当前 PyTorch MPS profiler 只报告 CPU activity，因此总 FLOPs 未精确统计。
- 持久身份注册表本地原子 JSON 保存、重启后继续分配和摘要记录通过。并发写入与远端存储不在该实验范围。
