# 功能能力首轮正式基线

本次运行验证固定数据规模下的训练、验证和规模外推能力；不是模型能力通过结论。

- 配置：`project/configs/models_training/learning/neuron_comparisons/functional/functional_capability_suite.json`
- 模型：单份共享参数 `ModelNeuron(input=3, hidden=32, message=1)`；每个样本持有独立状态。
- 每族训练 4096 个样本（512 次优化更新），验证与规模外推各 512 个样本。使用配置声明的独立 seed 域；封存测试种子 23003 未读取。
- MPS 结果见 `results.json`。低样本 CPU/MPS smoke 见 `../functional_capability_smoke/`。
- 四族验证均未达到冻结目标。集合归约 MAE 1.466、排列最大变化 8.045；分组绑定 MAE 1.555、排列最大变化 0.514；干扰回忆 MAE 0.750、阈值内精确回忆率 2.34%；条件路由 MAE 0.639、精确回忆率 5.86%，低于均匀选键基线 29.2%。
- 时序回忆与路由的分段状态重放最大差异为 0；但模型输出仍对候选排列高度敏感。集合归约优于训练均值基线，绑定和时序回忆/路由表现接近或低于简单基线；规模外推未达到阈值。
- 结果揭示当前顺序状态处理严重依赖排列，且分组绑定无法稳定保留身份关系。它提示输入/计算路径存在限制风险，但不单独证明模型理论上不可表达。封存测试没有读取。
- 组合任务已有固定域映射生成器和独立 oracle，但本轮未训练组合任务；仅前三类及 keyed-memory 路由参与正式训练评估。能力套件的这一阶段交付了任务/数据契约和可复现基线，未证明模型达到能力目标。
