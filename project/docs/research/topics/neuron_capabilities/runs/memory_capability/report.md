# GRU 状态能力、记忆边界与输出适配

## 验证范围

使用 `ModelNeuron.state_update` 当前 GRUCell，不依赖聚合器。一个模型在同一训练过程中共享权重并处理三个任务族：标记值延迟回忆、A/B 次序识别、带中途覆盖写入的干扰恢复。任务 adapter 只把序列事件编码成 8 维可观察输入，并把一个连续输出解码为回忆值或阈值为 0.5 的分类；oracle 不进模型。

基线在 MPS 上用 6 seed，隐藏维度 64、25,729 参数；每族每 seed 512 条训练序列，长度 8/16/32，12 epoch，训练长度外测试每族 512 条。64/128 步为独立外推验证，每族各 256 条。训练集、验证集、封存测试和外推验证使用独立 seed。精确配置在 `baseline_config.json`，完整逐 seed 指标在 `results.json`。

## 现有 GRU 基线

| 能力 | sealed test MAE/准确率 | reset 控制 | 随机丢状态控制 | 64/128 步外推 |
|---|---:|---:|---:|---:|
| 延迟回忆 | MAE 0.0484 | MAE 0.7937 | MAE 0.8125 | MAE 0.2105 |
| A/B 次序识别 | 准确率 100% | 准确率 51.5% | 准确率 85.1% | 准确率 89.9% |
| 覆盖写入与干扰恢复 | MAE 0.0712 | MAE 0.7942 | MAE 0.3968 | MAE 0.3478 |

延迟回忆在训练长度分布内达到 0.05 阈值，reset 与随机丢状态明显变差，说明 GRU 隐状态在任务中有实际作用。次序识别也依赖状态。覆盖写入未达到 0.05 阈值。所有任务的 64/128 步外推都明显退化，说明当前证据只支持有限跨度；不能把 32 步训练结果外推为长期记忆能力。

序列在中点切开后从 caller-owned state 继续，最大预测差为 0；恢复共享模型权重和同一份独立状态后最大差也为 0。模型状态图的新增/删除/重排身份测试确认既有 ID 保留原状态、新 ID 从零状态开始。图权重与调用方状态分别序列化，不按神经元身份复制模型参数。

## 容量候选：PyTorch LSTMCell

按参数量匹配，PyTorch LSTMCell 75 隐藏维为 25,576 参数，对比 GRU 的 25,729；两者使用相同数据、训练长度、epoch、batch、更新数和优化器。六 seed sealed-test 平均 MAE：

| 任务 | GRU | LSTMCell | 判定 |
|---|---:|---:|---|
| 延迟回忆 | 0.0628 | 0.5236 | LSTM 明显较差 |
| 次序识别 | 准确率 100% | 准确率 92.5% | LSTM 较差 |
| 干扰恢复 | 0.0853 | 0.5915 | LSTM 明显较差 |

64/128 步外推亦未改善。按当前任务和固定训练预算，保留 GRU，不增加 LSTM 状态实现；这不是对更长训练或其他 LSTM 初始化的普遍结论。

## 多通道任务输出 adapter

使用同一个 `ModelNeuron` 和 GRU 状态，将其 `output_projection` 扩为三通道：channel 0 连续延迟回忆，channel 1 次序分类，channel 2 连续覆盖写入。每个样本的任务上下文是输入的一部分，adapter 只选择和解释输出通道。此 checkpoint 中核心状态更新和输出 projection 都属于同一个共享模型；没有按 task/identity 建独立核心权重，也没有推理时快权重。训练配对比较使用 6 个新 seed、相同样本和更新数。

| 任务 | 单输出 GRU MAE/准确率 | 三输出 GRU MAE/准确率 | 64/128 外推：单输出 / 三输出 |
|---|---:|---:|---:|
| 延迟回忆 | 0.0697 | 0.0801 | MAE 0.2259 / 0.1558 |
| 次序识别 | 100% | 100% | 准确率 92.9% / 98.8% |
| 覆盖写入 | 0.0686 | 0.0994 | MAE 0.3355 / 0.3385 |

三通道方案在次序外推上更好，对其余两个任务的训练内 MAE 略差；它实现了可见上下文下的多类型解码，但没有带来全面精度提升。参数 25,987，比单输出多 258（约 1.0%）；平均训练时长约 3.99s，对比 3.95s。

同一个 `shared_model_state.pt` 已用 `weights_only=True` 加载至一个 `ModelNeuron`，恢复 25,987 个参数；输出通道映射记录在 checkpoint 与逐 seed JSON 中。adapter 不含可训练参数；所有输出权重均计入模型参数。

## 决定与边界

- NE-025.1：完成 GRU 延迟、次序和覆盖干扰基线；随机 reset/drop 确认状态价值，按 caller state、稳定 ID 和权重/状态 checkpoint 分离验证生命周期。
- NE-025.2：当前 GRU 保留；参数匹配 LSTMCell 对照在三项任务均无收益，不新增状态算子。
- NE-025.3：三通道输出可由一份共享 ModelNeuron checkpoint 支持；adapter 只做任务通道选择，长跨度能力仍未建立。
- 至少延迟回忆通过训练内 MAE 阈值；64/128 外推以及覆盖写入未通过，已如实保留失败边界。结果仅适用于这些合成任务。
