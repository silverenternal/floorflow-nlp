# 首轮神经元能力任务矩阵

## 研究边界

目标是评估共享参数、可携带调用方状态的模型神经元是否具备通用计算能力。任务输入、任务上下文和状态均可按任务定义；adapter 只编码可观察输入、调用同一神经元并解码输出，不执行任务答案算法。首轮只用完全合成数据，不声称模拟真实生理神经元。

误差分两类记录：**表示/接口限制**（输入或状态契约无法表达所需信息）和**学习失败**（信息已进入模型但拟合或泛化未达阈值）。报告必须记录分类依据，不能仅凭损失高就断言架构不可表达。

| 能力族 | 最小任务与输入/输出 | 可见上下文与状态 | 独立参考解 | 指标与首轮目标 |
|---|---|---|---|---|
| 集合归约 | 输入 `values[N]`，输出总和标量；训练 N=4/16/64，规模外推 N=256 | 无任务答案提示；无状态；排列不变 | 直接对原始 values 求和 | MAE ≤ 0.05；相对误差 ≤ 1%；排列差 ≤ 0.01 |
| 分组非线性绑定 | 输入 `group[N]`, `role[N]`, `value[N]`，每组两种 role；输出 `Σ_g A_g B_g`。训练组数2/4/8，留出16 | group/role 是本样本可观察身份，样本间随机置换；无状态 | 按原始 group 与 role 分桶后乘积求和 | MAE ≤ 0.05；相对误差 ≤ 1%；任意输入置换输出差 ≤ 0.01 |
| 干扰时序回忆 | 输入事件 `(key,value)` 序列及末尾 query key；输出该 key 最近一次写入值。训练长度8/16/32，外推64/128 | query 是可见上下文；每个时间步共享权重，调用方传递 recurrent state；无目标提示 | 按时间顺序扫描并保留 query 对应的最后值 | MAE ≤ 0.05；精确回忆率 ≥ 99%；状态重放一致率 ≥ 99% |
| 条件路由 | 输入 selector 和候选值 `values[K]`，输出 selector 指定项 | selector 与候选项均可见；无隐藏提示；无状态 | 索引选取 | 分类准确率 ≥ 99%；selector/候选排列等变性 ≥ 99% |
| 组合任务 | 两个随机有限映射 `g`、`f` 与输入 x，输出 `f(g(x))`；训练留出规则组合 | 映射表及 x 均可见；无状态 | 对原始映射表连续查表 | 准确率 ≥ 99%；未见组合准确率 ≥ 95% |

## 数据与评价协议

- 每个任务独立固定生成器、样本身份、适配器、解析器及 oracle；真值只从生成器原始结构和 oracle 计算，绝不由被测模型输出产生。
- 划分使用独立命名种子和身份域。训练/验证用于拟合与选择；封存测试只在适配器、训练规则和阈值冻结后运行。规模、序列长度、group 身份或规则组合的留出是有意外推，需单独报告。
- 可观察 task/context 属于输入；label、oracle 结果及任何未来事件均禁止进入推理输入。训练时辅助 hint 首轮禁用。
- 所有首轮数据为程序生成合成数据，来源为本仓库生成器，许可随项目；不含真实受试者或生物数据，不可用于生理真实性结论。
- 数值容差在配置和封存测试前固定。基线至少包含常数/训练均值与解析 oracle；未达到目标仍是有效失败结果，不得调阈值掩盖。

## CLRS 复用决策

候选独立扩展为 CLRS 官方 BFS 数据/算法。源码仓库 `google-deepmind/clrs`，许可 Apache-2.0；检查到的源码提交为 `6d5728b9efadf8648413c8c473929a733caacced`。官方算法/采样器适合提供独立算法参考，但官方训练示例依赖 JAX，当前 NewEra 核心是 PyTorch 且首轮三个能力任务可由小型独立 oracle 完整覆盖。因此此阶段不引入 CLRS 依赖、不复制其实现、不宣称已适配；完成三族闭环后再评估薄数据 adapter 的兼容成本。临时 clone 位于仓库外，不进入项目文件树。
