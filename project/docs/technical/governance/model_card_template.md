# 模型卡模板

状态：模板；公开发布前填写并与具体模型版本绑定。未知、未评估或不适用的项目须明确说明，禁止用空白或推测结果表示通过。发布流程和风险要求见[训练协议](training_project_protocol.md)及[安全与生命周期控制](security_lifecycle_controls.md)。

## 身份与来源

- 模型名称、版本、发布日期、维护者/联系方式：
- 模型结构、任务、输入输出模态、参数规模：
- 权重、分词器、配置、代码提交和评估报告的不可变指纹与位置：
- 初始化权重/第三方组件、来源、许可证与使用条件：
- 状态：研究中 / 已评估 / 其他，并附支持证据：

## 用途与边界

- 预期用户、用途、使用环境及前提：
- 不适用或禁止用途、重要限制、已知失败模式：
- 高风险用途是否涉及，以及适用性审查结论：

## 数据与训练

- 训练/验证/测试数据版本、来源与许可摘要，敏感信息处理与排除范围：
- 数据处理、去重、划分、污染检查与合成数据占比：
- 训练代码、配置、随机种子、主要超参数、计算资源和成本范围：
- 已知数据缺口、代表性限制及不可披露内容的说明：

## 评估、安全与公平性

- 数据集与版本、任务、指标、解码设置、样本数、结果及不确定性：
- 分组表现、公平性评估方法、覆盖不足的群体及限制：
- 红队/对抗测试范围、已知缺陷、缓解措施及尚未解决的风险：
- 超时、失败、缺失样本和未运行评测：

## 使用与生命周期

- 硬件/软件要求、使用方法及资源消耗：
- 发布记录、监控与回滚/停用方式、支持与问题反馈渠道：
- 适用法律与许可证审查状态，以及不构成合规声明的边界：
- 填写人、复核日期、证据链接与下次更新条件：
