# NewEra 的研究方向：基础神经元与能力演化

状态：研究方向与假设，非模型能力声明。项目长期目标是探索可由基础神经元单元构成、组合并不断学习的通用模型；这里的“全能性”是研究愿景，不预设任何有限单元或现有系统已经具备所有任务能力。

## 研究出发点

本项目采用明确的工程抽象：**每个神经元是统一模型架构的一次独立运行**。所有神经元暂时共享一份模型权重；各神经元可拥有独立显式状态、输入和拓扑位置，但不会为每个身份复制参数。它不是共享图传播算子中的一个待处理向量或标量操作。连接负责模型运行之间的信息传递，变度聚合属于统一神经元模型架构内部；组合框架负责连接、调度和资源边界。

生物学研究表明，某些生物神经元的树突和时空动力学可以执行比简单加权求和更丰富的计算，也有工作用多层人工网络近似特定神经元模型的输入输出行为。这些结果为本项目的模型化单元提供研究动机，但不直接决定其内部结构或工程实现。

上述工程约定是 NewEra 的设计目标，不是声称生物神经元等同于任意人工模型，也不表示所有模型化神经元具有相同能力。生物研究对象、数据和建模方法不同，不能把近似结果当作生物事实或通用能力证明。新理论或新证据出现时，应修订假设和实验，而不是把当前表述固化为不可挑战的前提。

## 待验证的核心问题

能否设计一个足够简单、可训练、可组合的基础神经元，使其在受控计算和数据预算下，展现有用的局部计算、状态维持或适应能力，并通过组合与学习获得更广泛的任务能力？“简单”应同时说明参数量、计算量、内存、状态、延迟和训练成本，而不是只比较单元数量。

统一模型内部结构、学习规则、状态和交互方式均为开放问题：状态、分支、局部路由、动态生长或其他机制都只是候选，不要求所有实现同时具备，也不预设生长或新生专家必然有效。图传播层可复用为模型运行间的路由候选，但仅有共享更新算子处理节点向量不构成模型化神经元。未来若考虑每个神经元使用不同权重，须用预算匹配对照证明其收益足以覆盖参数、存储和训练成本。

## 从假设到证据

1. **最小单元**：分别测试输入输出、可训练性、状态/时间依赖（若有）、稳定性和计算成本，记录失败与边界；无状态实现也可作为候选。
2. **组合与学习**：测试多个单元的连接、信息传递、训练和组合扩展，分析是否只是把复杂性转移到单元内部。
3. **跨任务能力**：以预先定义的任务集、泛化划分和评估协议测量迁移、适应或持续学习，记录遗忘和失败；不以单个任务或代理指标证明“全能”。
4. **公平对照**：与简单标量神经元、小型 MLP 或其他适配的基线进行受控比较；尽量匹配参数、训练计算、数据量和推理成本，无法同时匹配时分别报告各预算和差异。比较时记录多个种子或解释样本不足，并对候选机制做消融。

任何结论应可被新的实验推翻：记录基线、假设、配置、指标定义、预算、失败、限制和未覆盖范围。实验发现无优势同样是有效结果。安全、数据隔离与资源边界适用于所有分支。

## 研究阶段与实现约束

研究分支可独立替换、重写或删除神经元实现；不要求其继承特定抽象、维持旧内部接口或包含固定子模块。仅在某实现用于跨模块集成、正式对照或对外发布时，声明当次所需的输入输出、状态/参数语义、依赖和可复现边界。实验性 API 可明确标记为不稳定；版本、兼容性和迁移要求随影响范围决定。

目标是加快发现可行机制，不以保留既有结构、历史配置或旧名称为目的。不得为了便利破坏数据隔离、泄露凭据、绕过资源预算或将未验证结果作为已实现能力。
